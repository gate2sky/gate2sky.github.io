intergate is starting.

  Dashboard: https://{{ .Values.domain }}
  Tunnels:   https://<name>.{{ .Values.domain }}
  SSH:       ssh -p {{ .Values.ssh.publicPort }} -R <name>:80:localhost:3000 {{ .Values.ssh.publicHost | default .Values.domain }}

Point {{ .Values.domain }} and *.{{ .Values.domain }} to Traefik in DNS.
{{- if and .Values.traefik.enabled .Values.traefik.ssh.enabled }}

Traefik needs a TCP entry point named "{{ .Values.traefik.ssh.entryPoint }}" listening on the SSH port and
exposed by its Service, e.g. with the Traefik Helm chart:

  ports:
    {{ .Values.traefik.ssh.entryPoint }}:
      port: 2222
      expose: {default: true}
      exposedPort: {{ .Values.ssh.publicPort }}
      protocol: TCP
{{- end }}

{{- if .Values.tcp.enabled }}
TCP ports {{ .Values.tcp.first }}-{{ .Values.tcp.last }} are served by the Service {{ include "intergate.fullname" . }}-tcp
({{ .Values.tcp.service.type }}). Point {{ .Values.tcp.publicHost | default (.Values.ssh.publicHost | default .Values.domain) }} at its address.

{{ end -}}
Unless config sets email delivery and admins, set them up in the dashboard
with a one-time link (run it again for a new one):

  kubectl -n {{ .Release.Namespace }} exec deploy/{{ include "intergate.fullname" . }} -- intergate setup-url
{{- if not .Values.persistence.enabled }}

persistence.enabled is false: a restart loses the setup, with the users,
subdomains and SSH host key.
{{- end }}

Manage subdomains, SSH keys and users from the dashboard, or from a shell:

  kubectl -n {{ .Release.Namespace }} exec -it deploy/{{ include "intergate.fullname" . }} -- intergate config
