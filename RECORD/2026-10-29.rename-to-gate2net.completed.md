# gate2sky becomes gate2net

Done on branch `claude/charming-ramanujan-lzvg1g`, before the repository
moves to the `gate2net` organization (gate2net/gate2net.github.io) once the
branch is merged. Older records keep the old name.

- Everything is renamed: the Go module (`github.com/gate2net/gate2net.github.io`),
  `cmd/gate2net`, `cmd/gate2net-gui`, `deploy/helm/gate2net`,
  `gate2net.example.yaml`, binaries, paths (`/etc/gate2net`,
  `/var/lib/gate2net`, `gate2net.db`, `%APPDATA%\gate2net`), the systemd
  unit and user, `GATE2NET_*` variables, cookies, the image
  (`ghcr.io/gate2net/gate2net`), charts, Pages URLs, the client's SSH
  extensions (`udp-forward@gate2net`, unreleased before), the landing ("gate
  to the net").
- Kept working from gate2sky: its configuration (`$GATE2SKY_CONFIG`,
  `./gate2sky.yaml`, `/etc/gate2sky/gate2sky.yaml`, `gate2sky.yaml` next to
  `$GATE2NET_CONFIG`), `GATE2SKY_DATA_DIR` in the wizard, and `gate2sky.db`,
  renamed to `gate2net.db` on start. "gate2sky" stays a reserved subdomain.
  Sessions don't survive (cookie names changed).
- README "Upgrading from gate2sky" has the manual steps for a systemd
  install; setup.sh does not migrate one by itself.
- After the move: GitHub Pages for gate2net.github.io, the ghcr.io packages
  and the release workflow's permissions must be set up in the new
  organization; nothing in the code points to the old one.
