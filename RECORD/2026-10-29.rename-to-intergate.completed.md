# gate2net becomes intergate

Done on branch `claude/confident-mccarthy-02xu9i` (gate2net/gate2net.github.io#12,
with the new logo), before the repository moves to jgermade/intergate, whose
GitHub Pages site (https://jgermade.github.io/intergate/) serves the landing,
setup.sh and the Helm repository. Older records keep the old names.

- Everything is renamed, as in the gate2sky rename: the Go module
  (`github.com/jgermade/intergate`), `cmd/intergate`, `cmd/intergate-gui`,
  `deploy/helm/intergate`, `intergate.example.yaml`, binaries, paths
  (`/etc/intergate`, `/var/lib/intergate`, `intergate.db`,
  `%APPDATA%\intergate`), the systemd unit and user, `INTERGATE_*`
  variables, cookies, `/__intergate/auth`, the image
  (`ghcr.io/jgermade/intergate`), charts (`oci://ghcr.io/jgermade/charts/intergate`),
  Pages URLs, the landing.
- Pages is now a project site, under `/intergate/`: the release's pages job
  reads the Helm index being served from
  `https://<owner>.github.io/<repository>/charts/index.yaml`, and Build's
  landing check allows links to `jgermade.github.io`.
- Kept working from gate2net (released as v0.0.11) and gate2sky: their
  configuration (`$GATE2NET_CONFIG`, `./gate2net.yaml`,
  `/etc/gate2net/gate2net.yaml`, `gate2net.yaml` next to `$INTERGATE_CONFIG`,
  then the same for gate2sky), `GATE2NET_DATA_DIR` in the wizard, and
  `gate2net.db` (or `gate2sky.db`), renamed to `intergate.db` on start. The
  desktop app moves `gate2net/app.json` to `intergate/app.json` and removes
  gate2net's autostart entry when its own is switched. "gate2net" and
  "gate2sky" stay reserved subdomains. Sessions don't survive.
- The SSH names for UDP stay `udp-forward@gate2net`,
  `cancel-udp-forward@gate2net` and `udp@gate2net`: released clients and
  servers keep understanding each other.
- Helm: `nameOverride` (new) keeps a gate2net release's resource names and
  volume when it is upgraded to the intergate chart; Build renders that case.
- README "Upgrading from gate2net or gate2sky" has the manual steps for a
  systemd install, Docker and Helm.
- Not tried: `helm lint`/`template` (no helm in the dev container; CI's helm
  job renders the chart, the legacy case included).
- After the move: GitHub Pages, the ghcr.io packages and the release
  workflow's permissions must be set up in jgermade/intergate. setup.sh
  installs `intergate-<os>-<arch>.tar.gz`, so it needs a release made after
  the move: v0.0.11's assets are still named gate2net.
